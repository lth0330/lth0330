**주요 기능**
- 사업자번호 검증(국세청 API)을 거친 기업 회원가입, JWT 로그인
- 답사 신청과 전문가 자동 배정 — 같은 시 소속 우선, 그다음 Haversine 거리 기준, 일정 충돌 자동 회피
- 현장 보고서 — 흉고직경(DBH)·수고·좌표 측정값에 산림과학원 상대생장식(W = a × D^b)을 적용해 탄소흡수량 산출
- 수목 추천 — 탄소흡수력·토양·날씨·면적을 100점 만점으로 점수화해 22종 중 TOP 3 추천
- 누적 탄소흡수량에 따른 인증마크 등급(Bronze~Platinum) 자동 발급과 이메일 발송
- 관리자 대시보드, 지역별 탄소 배출량 통계(KOSIS)

**담당 역할 상세**
- 현장 답사 보고서와 나무 측정 데이터 입력 기능, 나무 데이터 CRUD API
- 상대생장식 기반 탄소흡수량 계산 로직, 좌표 기반 위치 매핑과 지도 시각화
- ESG 보고서 생성과 이메일 자동 전송
- Java Stream `groupingBy`로 ESG 보고서 집계 로직을 바꿔 처리 시간 약 40~70% 단축


- 레트로 필름 톤 디자인과 모바일 반응형
